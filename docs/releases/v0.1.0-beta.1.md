# Technolife RustDesk Configurator v0.1.0-beta.1

Primeira versão Windows x64 disponibilizada para testes em campo.

## Funcionalidades

- Detecta instalações existentes do RustDesk.
- Instala automaticamente RustDesk 1.4.9 quando necessário.
- Utiliza o pacote oficial do RustDesk.
- Valida o SHA-256 antes da instalação.
- Aplica automaticamente a configuração do servidor Technolife.
- Gera logs de diagnóstico.
- Evita reinstalação quando RustDesk já está presente.
- Executável Windows x64 self-contained.

## Comandos

```text
status
configure
setup
```

## Plataforma

Windows 10/11 x64.

## RustDesk homologado

RustDesk 1.4.9.

## Status

Beta destinada a testes em campo.

## Limitações conhecidas

- O executável ainda não possui assinatura Authenticode.
- O Windows SmartScreen pode apresentar aviso.
- O teste em uma máquina Windows totalmente limpa ainda faz parte da homologação em campo.

## Segurança

O configurador não contém senha permanente, chave privada, credenciais administrativas ou credenciais de clientes.
